# 三世书条目式附录

用户主动要求“三世书、前世今生来世、生肖月日时、骨格、六亲”等内容时使用。本附录保留传统民俗的叙事感，但输出必须采用：**传统意象 → 白话解释 → 现实建议**。

先用 `scripts/sanshishu_safety.py` 处理任何收集到的传统文本，再写入 `reading.json` 的 `sanshishu_sections`。

## 推荐条目

| 条目 | 可保留的意象 | 白话落点 |
|---|---|---|
| 前世·今生·未来 | 责任、照顾、秩序、表达、自由等原型 | 过去习惯、当下课题、不同选择形成的未来路径 |
| 论夫妻相 | 针锋相对、互相迁就、聚少离多 | 冲突风格、沟通节奏、边界与修复能力 |
| 论婚姻运 | 缘分深浅、相处起伏 | 候选关系模式，不写重婚或必然分离 |
| 论子女缘 | 教养、照顾、晚辈缘 | 亲子互动与教育方式，不写数量、性别和生育结果 |
| 六亲与兄弟 | 亲疏、援手、各自发展 | 家庭支持形式、距离感、金钱与责任边界 |
| 生肖月日时 | 季节、日时与生肖的传统组合 | 性格气质和环境适配，不与八字主分析重复 |
| 骨格与形伏 | 牛骨、狮子等象征形象 | 刚直、温顺、行动或社交风格；不作身体判断 |
| 学堂、屋宇、手艺 | 学习、居所、技艺 | 学习方法、住房决策、可培养技能；不说房屋危及性命 |
| 先天财富 | 进退财、衣禄、食禄、田业 | 现金流、守财、收入结构与劳动方式；不写横财保证 |
| 佛缘与善行 | 积福、布施、修心 | 公益、诚信、克制、修复关系和规律生活；不推销仪式 |

## 必须改写或省略

- 寿数、寿终、具体死亡年龄、死法、棺木、送终人数：改写为“本版不展示寿命或死亡方式预测”。
- 疾病名称与器官断言：改成一般生活方式提醒，并提示症状、家族史和筛查应咨询医生。
- 克亲、刑克、前世作恶导致现世疾病或失亲：改成家庭沟通、责任分配和关系边界。
- 必有几个孩子、男女性别、绝嗣：改成亲子互动、照顾晚辈或培育作品的方式。
- 重婚、夫妻必散、必受欺侮：改成关系中的冲突模式、修复条件和风险信号。
- 烧纸钱、元宝、香烛、法事金额、经文天数：删除。不建议购买物品或付费仪式，可用公益、守信和实际改善表达“积善”。
- 保证横财、官位、名扬四海：改成能力与机会的象征，不作结果承诺。

## reading.json 结构

```json
{
  "sanshishu_sections": [
    {
      "title": "论夫妻相",
      "traditional": "针尖对麦芒，若能彼此体谅，关系可缓。",
      "plain": "双方都可能坚持自己的逻辑，冲突容易迅速升级。",
      "advice": "约定暂停信号，一次只解决一个问题，并避免在情绪最高点作重大决定。",
      "notice": "传统民俗寓言，仅用于文化阅读和自我反思，不是事实预测。"
    }
  ]
}
```

传统文本必须经过 `soften_traditional_entry()`；如果过滤后只剩提示语，也不要为了填满版面重新补写危险断言。
